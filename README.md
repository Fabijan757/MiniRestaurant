# MiniRestoran

Jednostavna aplikacija za naručivanje hrane u restoranu.

## Tehnologije
- C#
- .NET
- MySQL
- Git

## Funkcionalnosti
- Prikaz proizvoda iz MySQL baze
- Dodavanje proizvoda u narudžbu
- Izračun ukupne cijene
- Spremanje narudžbi i stavki u bazu
- Ispis računa

## Pokretanje
1. Instalirati .NET SDK i MySQL.
2. Kreirati bazu `mini_restoran` i potrebne tablice.
3. Postaviti varijablu okruženja `MYSQL_CONNECTION`.
4. Pokrenuti aplikaciju naredbom `dotnet run`.
